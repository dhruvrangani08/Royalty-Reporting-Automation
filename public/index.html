Headless service. There is no user interface here — the student portal is a separate application.

Health probe
GET /api/health — requires Authorization: Bearer <HEALTHCHECK_TOKEN>. Returns 200 when config resolves and Supabase is reachable, 503 when a dependency is down, 401 otherwise.
Where the sync runs
Not here. A serverless function is capped at 60 seconds; the daily sync is budgeted at two hours and the backfill at eight, so both run on a scheduled job outside Vercel.
